### 👨‍💻 Sobre mí

- 🔐 Me enfoco en **ciberseguridad ofensiva**, **DevOps** y **cloud**.
- ☁️ Despliego infraestructura en **Azure** con **Terraform** y orquesto contenedores con **Kubernetes** y **Helm**.
- 🧪 Construyo laboratorios de **pentesting** aislados (Kali Linux + Metasploitable) para practicar de forma ética.
- ⚙️ Automatizo pipelines con **GitHub Actions** y pruebas con **Karate** y **Serenity BDD**.
- 🌱 Ahora mismo: enumeración con Nmap, políticas de red en Kubernetes y hardening de clusters.
